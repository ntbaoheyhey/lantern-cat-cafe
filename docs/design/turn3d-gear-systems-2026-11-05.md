## The local loop
Three cats prepare for three waves and the Yarn Giant. Each cat equips Weapon, Outfit, Charm and Relic. The catalog contains thirty original items: eight class pieces per cat and six shared charms/relics. Common, Uncommon, Rare, Epic and Legendary reuse the main game's rarity vocabulary; attack, defense, HP, crit, healing, shield, Initiative, cooldown and status chance are legible stats. Each item has one main stat, up to two affixes, flavor, class fit and a named property at Rare or higher.

The loadout screen previews changes on the actual GLB, shows stat deltas and set activation, and provides reset/auto-equip. Equipment ownership is exclusive within a party; incompatible slots/classes and equipment changes during combat are rejected atomically. Mid-run equipping preserves missing HP rather than creating a free heal loop. A defeated cat cannot equip. Auto-equip optimizes a local score with deterministic tie breaks; it is not a solver that promises an optimal human build.

After each wave a separate seeded loot stream offers three distinct choices. It cannot consume combat random rolls. The selected item joins the in-memory inventory. Cafe rest allows equipment changes and displays remaining shared supplies before the next numbered round. Five consumables cost the acting cat's action and consume limited charges: Warm Milk Tonic (+150 HP), Shield Biscuit (+80 shield), Quicken Yarn (two earlier positions), Clearleaf Tea (cleanse +40 HP), Starlight Treat (+40 charge). Supplies cannot be used freely at rest. No levels, purchasing or permanent progression were added.

The run summary includes rounds, actions, found items, damage dealt/taken, healing, shielding and an MVP calculated from contribution totals. Results may be defeat as well as victory. Restart discards the whole run. The seed is copyable through local review controls; no save or resume persistence is implied.

## Combat consequences
Properties include a once-chaining Needle Lantern, neighboring shields, after-heal shielding, first-action Initiative, longer burns, stronger healing, ultimate cost reduction, boss stagger, cleanse on guard, life return, charge gain and reflected damage. The pure rules tests exercise every named property through actual legal actions. Hearthloom, Moonwick and Mossbrew have distinct two-/three-piece bonuses and visible activation hints; meshes and rarity emissive accents update with loadouts. Weapon shape/trail accent, outfit silhouette, charm and Relic sockets come from original code geometry. The item viewer uses that same attachment code.

Round order is fixed by integer Initiative, then seeded tie break and ID. Gear never inserts a fractional scheduler. Cooldowns and duration effects expire on round boundaries; Quicken and Push Back only reorder pending actors. One Quicken per recipient per round prevents repeat grants. Equipment, begin, action, loot and continue commands form a replayable local transcript. Playback drains forced burn/skip boundaries before loot and after the final command without inventing a player's next action.

## Boundaries and possible later mapping
All new rules live inside `packages/game-rules/src/squad/`. All runtime art, post-processing and audio load under `squadCombat` and `squadCombat3d`, both default off. The preparation screens are part of this same experiment, so no separate gear flag is necessary. Production inventory, real Relics, wallets, forge, market, chain contracts, Supabase records and economy amounts are not read or written. Generated Deno import maps acknowledge the new local modules but no server handler or deployment is changed.

A future adapter could map a real inventory item to a validated sandbox loadout, map Relic rarity to cosmetic socket treatment, and translate approved rune/forge effects to a versioned rules schema. That adapter would need explicit product/economy authorization, ownership validation, versioning, persistence design and replay migration. It does not exist here. The phrase “Avalanche Relic” is a catalog flavor tag only. This work adds no Avalanche integration, chain transaction, server grant or durable reward.

## Balance scope
Thirty seeds per composition/policy/equipment/encounter are archived. The active proxy reads legal choices, committed intents and current inventory, including loot compatibility; it has no future RNG or enemy information. Manual humans have not been measured. Campaign starter gear is the target difficulty; fully legendary equipment is an intentionally powerful ceiling. The isolated boss practice uses 3400 HP / 220 attack because it omits the campaign's three loot opportunities; campaign boss uses 4000 HP / 245 attack. Threat-based interruption weight is reduced in isolated boss practice, where overvaluing an immediate interrupt caused poor long-term resource choices. Tunings belong only to the squad config; failed trials remain evidence.
