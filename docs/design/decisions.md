# Design decisions — living draft

- [Restore the existing verification baseline](../decisions/mission-baseline-compatibility.md): combine minimal repairs needed by the strict complete-suite gate; preserve desktop scope and existing responsive behavior.

- [Give HUD status and guidance their own rows](../decisions/baseline-hud-layout.md): preserve the complete next action and reserve a readable XP track at both desktop targets.

- [CXP1 companion preview](../decisions/pets-preview.md): twelve original IDs, DEMO_PREVIEW thresholds/levels/equip-two, local persistence and runtime isolation; gameplay reserved for CXG1.

- [ART1 art pipeline and palette](../decisions/art-pipeline.md): fixed cafe-night-v1 palette, native pixel contracts, dependency-free tools, honest provenance and twelve pet art reservations. Signed by Codex under full user authority, 2026-11-01.

- [Bound v2 request input before authentication](../decisions/cxn3-request-body-limits.md): preserve the8192-byte contract, bound stream lifetime and cancellation, and retain authentication/budget gates before game work.

- [CXU4 Hero, Help and shared states](../decisions/cxu4-hero-help.md)
- [CXU5 Map data and presentation](../decisions/cxu5-map-data.md): real limits, advisory boss power, session-scoped history, preserved compact map.

- [CXC2 public Fuji proof](../decisions/cxc2-fuji-proof.md): lazy Help panel, bounded same-block reads, honest partial results and a30-second cache.
