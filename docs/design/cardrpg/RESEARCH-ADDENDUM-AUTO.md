# Automatic battles · presentation addendum
REFERENCE: docs/design/cardrpg/RESEARCH.md; docs/design/cardrpg/research-matrix.json; docs/design/cardrpg/sources.json; docs/design/cardrpg/DESIGN.md

The player's decisions belong to collecting companions, choosing three cats, arranging rows and equipping items. Fight starts an uninterrupted, seeded presentation. Playback controls change presentation speed or visibility. The same controller produces the watched result, skipped result and replay.

| Existing research row | Supported finding | Application in this pass |
| --- | --- | --- |
| AFK Journey, AFK / AFK2 | Class equipment and progression reduce equipment housekeeping | Show power, four equipped slots and set progress before Fight. Keep the existing individual gear rules. |
| Epic Seven, E7 | Character presentation supports attachment, development friction can dominate the loop | Give starter skills their own pose and silhouette. Keep collection and improvement one click from results. |
| Fire Emblem Heroes, FEH / FEH2 | Hub, first-clear goals, favourites and collection connect activities | Make the next chapter and equipment goal visible from the cafe. Reuse the existing destinations. |
| Raid, RAID | Gear slots and set thresholds create build targets | Compare equipped stats and expose two/four-piece progress. Deterministic tailoring provides a chosen target. |
| Monster Train, MT | Spatial formation conveys consequences | Separate front and rear rows and direct attention to the actor and target. |
| Sorare, SOR | Edition and seasonal supply denominations require explicit disclosure | Display both existing Relic-design caps and local counters alongside effort requirements. |

The existing matrix supports these mechanism-level conclusions. Specific camera timings, effect grammar, MVP summaries and pacing budgets are original presentation decisions for this prototype. Their quality will be measured locally. No additional web research or reference artwork is required for this pass.

The catalogue has 48 skills in total, including 12 ultimates, and 12 passive definitions. Evidence counts use those actual identities. New skills would exceed the scope lock.
