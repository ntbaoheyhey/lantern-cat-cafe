# Security test matrix

Maps each security requirement to the test that proves it. Server tests run offline against disposable PGlite with the real migrations in order and real Edge Function handlers; the demo concurrency control uses its in-memory store. The import guard uses scratch files, and the contract replay tests use Foundry's local EVM. None touch a live database, the Fuji RPC or a live account. Run server tests with `pnpm --filter @taskbar-hero/supabase-tests test`, the guard with `node scripts/check-deno-imports.mjs`, and contracts with `cd contracts && forge test`.

Unlinked test paths are relative to `supabase/tests/`. **GAP** means passing enforcement is missing. **KNOWN DEFECT** identifies a failing product requirement retained with `it.fails`, as required by CXN2; an expected failure is not evidence that the requirement passes.

## Not covered by any offline test (NOT VERIFIED)

- Live Supabase policies, grants and Edge Function secrets: tests prove the checked-in migrations, not what is applied live.
- The deployed RelicNFT contract's signature check: offline Foundry tests now cover replay and signature enforcement, but do not verify deployed bytecode or live transactions.
- Real Fuji RPC behaviour: receipts and `usedNonces` are faked through `ChainReader`.
