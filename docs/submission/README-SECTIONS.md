# README-SECTIONS.md

## Pitch
Taskbar Hero: Lantern Cat Cafe is a cozy cat card RPG where you defend the last lit shop on a chaotic street. Players build decks of cafe memories, battling the Tangle, a yarn giant born from abandoned tasks, to restore light to the street. It features unique card-based combat and a relaxing atmosphere set against a backdrop of cat-themed adventures.

## How to Play
1. **Deck Building**: Collect cards representing cafe memories and abilities.
2. **Combat**: Engage in strategic battles against Tangle minions using cat heroes (Mochi, Clover, Soot).
3. **Healing & Special Abilities**: Utilize healing tea brews and unique ultimates to turn the tide.
4. **Relic Collection**: Defeat the Yarn Giant boss to mint cafe memories as permanent Relics.

## How Avalanche is used
- **Guest Sign-in**: Players sign in using SIWE (Sign-In with Ethereum).
- **Sponsored Gas**: The game covers gas fees for a frictionless experience.
- **Relic Minting**: After defeating the boss, players mint Relics as ERC-1155 tokens on the Avalanche Fuji network.
- **Tokens & Market**: YARN ERC-20 tokens are used in the in-game market, with all transactions visible on Snowtrace.

## Architecture
The game is a browser-based RPG built using Phaser, with smart contracts deployed on the Avalanche Fuji network. It leverages ERC-1155 for unique collectibles and ERC-20 for in-game currency, ensuring a decentralized and transparent ownership experience for players.
