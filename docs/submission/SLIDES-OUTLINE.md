# Slides Outline

Slide 1: Lantern Cat Café, a cosy cat card RPG in the browser with Avalanche Fuji contracts.
Slide 2: The Story: The Lantern Cat Café is the last lit shop on a street knotted up by the Tangle and the Yarn Giant.
Slide 3: The Heroes: Mochi (tank, shield + lantern), Clover (healer, teapot), and Soot (mage, purple cloak).
Slide 4: Core Combat: Automated off-chain Three.js battles governed by deterministic TypeScript game rules.
Slide 5: Ultimate Showdowns: Cinematic ultimate abilities—Last Lantern Vow, Fourleaf Spring Brew, and Chimney Comet.
Slide 6: Boss Encounter: An escalating confrontation against the towering Yarn Giant woven from abandoned tasks.
Slide 7: Frictionless Web3 Onboarding: Instant guest sign-in using SIWE, with test AVAX dripped to the guest wallet for mint gas.
Slide 8: Permanent Cafe Relics: Victorious cafe memories minted on Avalanche Fuji via EIP-712 signed vouchers as ERC-1155 tokens.
Slide 9: The Wider Ecosystem: YARN ERC-20 utility tokens and RelicMarketV2 escrow trading on Fuji, verified on Snowtrace.
Slide 10: Technical Architecture: React and Three.js run the browser campaign. Supabase authenticates wallets and issues vouchers for the verified Fuji contracts.
