# The Lantern · Lane B review
REFERENCE: tools/cardrpg-big2/build.mjs; reports/cardrpg-big2/CARDRPG-BIG2-REPORT.md

Open index.html directly in a Chromium browser. The demo embeds its models, images, application and comparison captures. Allow the progress screen to finish before entering the cafe.

- Review studio opens all12 cats,10 ordinary opponents and3 bosses. Select an action, play or scrub it, compare cameras A/B/C and use Focus stage for a larger view.
- Before / after contains the captured comparisons. Brief checklist links to the card-game screens.
- Watch a battle now starts an automatic fight. Speed, pause, skip, camera and sound control the presentation.
- Mechanics lab starts with every experiment off. Its preview account is separate from the cafe account.
- Frame meter shows local samples since opening the overlay. The report contains the saved acceptance measurements.

The report lists opening hitches, sharpness and scale misses, each unit's tier, validation receipts and pending integrated checks.

To rebuild from the repository, run `nice -n 10 node tools/cardrpg-big2/build.mjs`. The build uses the repository dependencies and the Pillow environment documented in INTEGRATION-HOOKS.md. The generated HTML opens without those build tools.
