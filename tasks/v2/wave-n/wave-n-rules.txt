=== WAVE N ADDITIONS (31 Oct 2026, living draft). Read these first; the wave S shared rules below still apply. ===

1. Mission overrides win. If your mission card says a Tier 3 file is in YOUR ZONE (for example one
   new migration file, or a signed config number), that one item is allowed for this mission only.
   Everything else in Tier 3 stays a hard stop.
2. Migrations: a new migration file goes in supabase/migrations/ ONLY if your card allows it. Name
   it with the next free timestamp after the newest file there. It must be additive, idempotent,
   wrapped in begin/commit, revoke from public/anon/authenticated and grant to service_role. Never
   apply it to any live database. Put "APPLY BEFORE DEPLOY: <file>" as the second line of your report.
3. Deno import map: every Edge Function has supabase/functions/<fn>/deno.json generated by
   `pnpm gen:deno`. If you add or rename a file under packages/** that an Edge Function imports,
   run `pnpm gen:deno` and commit the deno.json changes. `git diff --exit-code -- supabase/functions`
   after gen:deno must be clean. (A missing map entry broke the live deploy on 30 Oct.)
4. GitHub Actions: do not run or trigger workflows. Verify locally. If `scripts/verify-pr.sh` is
   available, run it without --comment and paste its summary.
5. Secrets: never paste, log, commit or echo a database URL, password, service-role key, private key
   or JWT. If you meet one in a file or log, write "SECRET FOUND: <file>:<line>, masked" in the report
   and do not copy it. Never ask the user for one.
6. Live systems: read-only. You may read https://taskbarhero-eight.vercel.app and the public Fuji
   RPC. You may not call Supabase admin APIs, deploy, change Vercel, or send a transaction, unless
   the card says so (only AGN3 plays live with its own throwaway test wallet).
7. Language: write code, docs and reports in plain English. Keep existing Vietnamese text as is.
8. Before you finish, re-read your card's TEST CASES list and mark each one PASS / FAIL / NOT
   VERIFIED in the report. A test case you did not run is NOT VERIFIED, never PASS.
