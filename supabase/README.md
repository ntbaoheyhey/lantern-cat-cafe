# Supabase

SQL migrations go in `migrations/` and Edge Functions go in `functions/`. The server (Edge Functions plus the service role) decides gold, gear, shards and the Boss Key, and signs Relic mint vouchers.

Edge Function `deno.json` import maps are generated by `scripts/gen-deno-json.mjs`.
Edit its auth or game template, run `pnpm gen:deno` from the repository root, and
commit the generated files. Directories with an `index.ts` entry point use the
game template unless their name starts with `auth-`; `_shared` is excluded.
The game template includes the extension mappings for game-rules modules,
including `content`. CI regenerates the maps and checks
`git diff --exit-code -- supabase/functions` to reject drift.
