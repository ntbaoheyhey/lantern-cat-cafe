# Q2: opaque silhouette scale, facing, field and number clarity

Learning started 2026-11-15T09:28Z. Product edits have not begun. Experiments completed before the implementation decision below.

Question: How can 4 staggered cats and 4–6 enemies remain equally readable at both desktop sizes, with no face/HUD occlusion and no lingering damage columns?

## Professional method under study
- Texture or geometry bounds include transparent padding; measure the visible rendered alpha first (Q2-alpha, Q2-box).
- Preserve a stable ground pivot when scaling or reflecting a unit; reflect by its native-facing metadata (Q2-flip).
- A bounding polygon can protect the important shape rather than a nominal image rectangle (Q2-bounds).
- Keep the camera projection constant and fit composition through unit scale and authored slots (Q2-local).
- Place short labels with explicit candidates and an overlap cost against protected features; avoid solving collisions by pushing everything to a screen edge (Q2-paper).
- Reserve the whole moving number footprint, cap its lifetime and count, and preserve one resolved value per hit (Q2-local).
- Verify the proposed method on actual painted units, and retain both the failed and chosen layout measurements (Q2-experiment).

## Animated size: bounded opacity hull experiment (before implementation)
Question: can the size system retain a <=5% inter-unit height range without changing the authored pose curves? Rest-alpha calibration alone misses rotation/pose expansion. Compare (a) the posed geometric rectangle and (b) the opaque pixel contour mapped through each current mesh triangle. Cache contour weights once; use barycentric interpolation against live mesh positions, then a foot-pivoted uniform scale correction only outside 98–102% of the measured common height. This preserves the pose's shape and width/height proportion; it does not author new poses. Reject a method if actual isolated alpha renders exceed the existing bar or if it erases readable motion.
Professional basis: [PBRT Triangle Meshes](https://pbr-book.org/4ed/Shapes/Triangle_Meshes) (formal technical document: interpolate coordinates using triangle barycentrics); [Three.js BufferGeometry](https://threejs.org/docs/pages/BufferGeometry.html) (doc: separate position, UV, index buffers); [Three.js Texture](https://threejs.org/docs/pages/Texture.html) (doc: image data and flipY must match upload). Existing Q2-alpha and Q2-box describe the alpha/geometry difference. Own experiment will compare both methods on the existing six desktop fixture cases, using the unchanged original rendered pixels for judgment.

Animated-size experiment results: `pose-normalize.json` rejects geometry bounds (cats shrink to 175 px and max/min stays 1.0686). Opacity hulls at 98–102% pass cats but one 900p ordinary-enemy comparison is 1.05063, still a FAIL.
