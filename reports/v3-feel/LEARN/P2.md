# P2: Soot drawn poses, anchored staff and Lantern Requiem
Question: How do identity-preserving key drawings replace the idle-only pilot without losing feet, colour, sockets or fixed action timing?
Study started2026-11-16T01:34Z. Sources below were inspected in P1 or reopened for this item. Build choices remain subject to the actual pilot films.

## Method learned before authoring
- Use clearly different anticipation/contact/hit/cast silhouettes; secondary deformation settles a drawing rather than inventing it (P1-lasseter,P1-experiment).
- One visible drawing per slot prevents ghosted anatomy (P1-attachments,P1-keys).
- Add per-drawing effect points; a point attached to the old hand cannot follow a newly painted arm (P1-attachments).
- Preserve a foot-local origin when changing artwork width; transform socket/face coordinates with exactly the same map (P2-transform).
- Texture source, alpha convention and colour decode must agree. Existing atlas materials decode sRGB manually and undo PMA only for PMA pages (P2-colour,P2-runtime).
- A full-pose layer must hide old attachments and restore them on clear/dispose; per-actor selection must not mutate cached data (P2-runtime).
- Sample drawings from the existing presentation time, including backward seeks,0.8/2.2s endpoints and speed scaling; do not invent another clock (P2-runtime).
- The full-body A2 experiment retained identity better than arm-only B retained action silhouette; use A first, four candidates per mandatory drawing, inspect best two (P1-experiment).
- K0 runtime painting and the currently assembled rig differ in proportions/lighting. Test the actual field baseline and the new layer before deciding whether K0 should use its approved painting on the same layer (P2-runtime).
- Rework the failed ultimate as a travelling tapered lantern-light strike and expanding impact shape, with finite erosion; cast/body/impact/residue must read separately (Q3-T17,Q3B-L02). No curtain/loop main shape.
