# S11 first-contact loading and journey soundscape

Prepared on 16 November 2026 before changing runtime sources. Healer endurance remains active; the experiments alter only isolated headless browser instances.

Sources and consequences:

1. [W3C Web Audio 1.1, decodeAudioData](https://www.w3.org/TR/webaudio/#dom-baseaudiocontext-decodeaudiodata), formal Working Draft, 22 September 2026. Decoding is asynchronous and runs outside the control/rendering threads. A fetched or pending pack is not a decoded pack; record both states at the actual request.
2. [MDN decodeAudioData](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData). Decoding requires the complete encoded file and resamples it to the context rate. Earlier loading must preserve the existing samples, rate and decoder.
3. [MDN getOutputTimestamp](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext/getOutputTimestamp). Its paired audio/performance clocks estimate device presentation. A source-call improvement does not establish physical onset, and a 33.76ms estimate still fails a 33ms gate.
4. [MDN AudioBuffer](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer). Decoded buffers reside in memory and can be reused. Keep the engine's cache and do not start dummy voices to warm it.
5. Local `apps/web/src/audio/engine.ts`: `music('battle'|'boss')` calls `preload`; `preloadVoices` warms only the roster's speech. `perform` starts cached samples synchronously, but awaits missing packs. These are separate pathways.
6. Local `battle-v3/battle-audio.ts`: the rendered roster triggers `preloadVoices`. This supplies a controlled browser-only warm-up point without changing action clocks or requiring another user gesture.
7. Local `depth/App.tsx`, `ui-v3/ShellV3.tsx`, `shell/DemoJourney.tsx` and `audio/scene.ts`: SHIP replaces ShellV3 with DemoJourney. ShellV3 owns the music/ambience effects, and DemoJourney has no equivalent. The sound-scene helper already distinguishes boss encounters and ordinary battles. This explains why the shipping judge journey bypasses scene audio.
8. Local `S11/impact-journey-{3,4}.json`: healer-corrected production13 completes both journeys, but first-contact estimates are 102.556/98.063ms. The observed combat contact and actual source-start attribution are preserved; full weapon/human/physical gates remain open.
9. Own experiments `S11/cold-contact-probe-{1,2}.json`, with immutable harness snapshots and raw events. Each compares four paired fresh contexts, two at each required size, with alternating method order, real Play free/Start trial gestures, original production assets and fixture rollback after every entry.
