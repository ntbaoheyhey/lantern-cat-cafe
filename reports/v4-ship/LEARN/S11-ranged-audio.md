12. [WebKit Cocoa audio reader](https://github.com/WebKit/WebKit/blob/main/Source/WebCore/platform/audio/cocoa/AudioFileReaderCocoa.mm): platform decoding is a separate implementation from Chromium. Test actual decoded samples rather than infer parity from file support.
