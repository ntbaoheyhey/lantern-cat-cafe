# S11 audio delivery preparation

Read on 16 November 2026 before preparing alternatives. Current ranged coverage/endurance uses the installed runtime without edits. Preparation stays in `work/`; no candidate is installed during a signed capture.

1. [W3C Web Audio 1.1](https://www.w3.org/TR/webaudio/#dom-baseaudiocontext-decodeaudiodata), formal Working Draft dated 22 September 2026: decoding resamples PCM to the context rate. Rebased sprite offsets must be checked at 48 and 44.1 kHz, independently of encoded size.
2. [MDN decodeAudioData](https://developer.mozilla.org/en-US/docs/Web/API/BaseAudioContext/decodeAudioData): decoding requires complete file data. Arbitrary HTTP ranges are not a replacement for complete independently decodable packs.
3. [MDN AudioBuffer.copyFromChannel](https://developer.mozilla.org/en-US/docs/Web/API/AudioBuffer/copyFromChannel): sample copying uses an explicit channel and sample offset. Preserve channel count and exact sample-frame boundaries when partitioning the already rendered PCM.
4. [RFC 9111 HTTP Caching](https://www.rfc-editor.org/rfc/rfc9111.html#section-2), formal Standards Track document: the request method and target URI form the minimum cache key. Reusing a pack across encounters can avoid repeated payloads; a cold first journey cannot assume that cache benefit.
5. [Vite public assets](https://vite.dev/guide/assets.html#the-public-directory): public files retain their names and are copied to the build unchanged. Manifest paths, encoded hashes and licensing must match any eventual installed files.
6. [FFmpeg libvorbis](https://ffmpeg.org/ffmpeg-codecs.html#libvorbis): encoder options control the output. Keep the already validated Vorbis quality setting, leading padding and native LAME scaling protocol unchanged; a smaller file alone is insufficient evidence.
7. Local `ranged-class-bake-1.json`, immutable PCM and installed manifest: 144 unique sprites cover ember/heavy/shadow/tide, with ice sharing tide's exact impact mapping. Keep all 36 balanced combinations per palette, nominal pitch, guards and source provenance.
8. Current `scene-journey-7.json`: scene-ready transfer is 30,042,340 B; audio responses total 5,339,285 B, including 954,763 B for the ranged pack (954,493 B encoded payload). The two encountered ranged palettes are ember and heavy. Images remain 22,861,499 B; audio changes alone cannot meet the 8 MB gate.

Prespecified comparison: measure the existing monolithic pack against four independent palette packs and a combined ember/heavy encounter pack with the original pack retained for other palettes. Compare actual encoded bytes and request counts for each single palette, the observed two-palette encounter, and all palettes. Reuse the signed pre-encoding PCM, never transcode the lossy delivery files. Require all selected complete sprites to retain zero lag, correlation >= .99 and absolute RMS difference <= .1 dB in Chromium/WebKit at both sample rates, using the same measurement helper. Preserve unsuccessful candidates. This experiment does not alter preload routing or establish real network savings, readiness, source admission, physical onset, perception or global acceptance.

Because comparison 2 introduced monolith priming, `ranged-delivery-cold-1.json` separately compares 16 fresh WebKit processes in a balanced order at both rates: eight with no primer and eight with both installed monolith formats decoded first. All 16 decoded the same reference WAV and exact failed ember WebM bytes. This does not reproduce the first failure or establish its cause. Operating-system decoder caches were not reset. Decode elapsed time is neither acoustic onset nor network readiness; no general WebKit incompatibility or resolved failure is claimed.

Decision: retain the installed monolith for this checkpoint and prefer separate palette packs for a later routing experiment. They save 394,272 encoded WebM bytes for the observed two-palette encounter; the combined encounter pack saves only another 4,020 B while increasing all-palette WebM payload to 1,510,694 B through duplicate fallback coverage. Separate palettes cost 10,376 B and three additional requests when all four are needed. These measured tradeoffs favor reusable palette selection, but actual cold/cached requests, readiness and complete roster routing must be tested before installation. No candidate is installed and no shipping transfer gate is closed; current images alone exceed 8 MB.
