# S11 landing title contrast

Read 16 November 2026 before product changes. Scope: the two-line SHIP landing title only; preserve the original unknown observations and all ART battle uncertainty. Do not claim global UI acceptance.

1. [WCAG2.2 contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): normal text requires4.5:1, large text3:1. Although the standard permits a brand-name exception, this item will measure the requested title contrast instead of clearing it by exception.
2. [W3C Filter Effects Level1](https://www.w3.org/TR/filter-effects-1/#funcdef-filter-drop-shadow), formal draft: drop shadows composite an offset alpha mask below the source. A computed transparent color alone does not describe gradient text; keep the original filtered rendering unknown.
3. [MDN background-clip](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/background-clip): text clipping paints the background within glyphs. Reset clipping when switching to an opaque text/backplate pair.
4. [MDN background-color](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/background-color): a specified opaque background supports a luminance comparison independent of artwork. Text must remain within that actual backing rectangle.
5. [MDN color](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/color): the rendered foreground and background must be evaluated together. Transparent text on artwork must not receive a solid-color contrast pass.
6. [Playwright addStyleTag](https://playwright.dev/docs/api/class-page#page-add-style-tag): temporary CSS can compare candidate treatments on an unchanged production page. Remove each injected style before the next method, retain geometry/names/copy, and validate the chosen treatment after an actual production rebuild.
