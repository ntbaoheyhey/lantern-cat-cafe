## Sources and decisions

- [NIST SSDF 1.1, PW.8.2](https://nvlpubs.nist.gov/nistpubs/SpecialPublications/NIST.SP.800-218.pdf): record tests and triage failures. A clean merge is not a quality gate.
- [Git merge-tree](https://git-scm.com/docs/git-merge-tree): predict the three-way result without changing HEAD, index or worktree; use exit status and the explicit conflict list.
- [Git merge](https://git-scm.com/docs/git-merge): checkpoint first; at the scheduled time use a reviewable merge before committing.
- [Git diff](https://git-scm.com/docs/git-diff): use NUL-separated names and compare the merge base to the incoming tip.
- [GitHub merge conflicts](https://docs.github.com/en/pull-requests/reference/merge-conflicts): resolve final content deliberately, with ownership and behavioral checks.
- [Our measured comparison](../S7/preflight-1.json): the two inventory methods below were run on the same immutable commit pair.
