# S2: measure the first session before polishing it

RS3 answer: let the guest act before asking for custody decisions. The existing guest EOA+SIWE and bounded gas drip already implement most of that mechanism. Keep wallet upgrade/export discoverable after ownership matters; do not add a provider account or replace custody before submission. [S2-PRIVY,S2-OPENFORT; existing guest.ts]

Research: CHI2012 found tutorial value depends on complexity; just-in-time instruction helped the complex study game but did not yield the same result in simpler games. The2022 implicit-tutorial pilot supports practice and timely feedback with limited generalizability. We should test short contextual prompts around the real café loop, not infer our retention from another game's study. [S2-CHI,S2-IMPLICIT]

Professional method:
- Define observable landing, battle, reward, receipt, forge/market/Spool, boss and proof checkpoints.
- Run fresh browser contexts rather than reusing stored wallets or tutorial completion. [S2-ISOLATION]
- Count real clicks and wall time from navigation; do not inject a save, HP, rage, results or virtual time.
- Observe browser exceptions, console errors, request failures and HTTP failures separately. [S2-NETWORK]
- Preserve the exact route, build mode and viewport with each result.
- Mark a blocked downstream step as blocked, never passed or silently skipped.
- Evaluate source-level/dev-route behavior separately from production preview.
- Use the measured drop-off list to choose the next change. [S2-ROBLOX]

Own experiment before tooling: tools/v4ship-lab/funnel/entry-probe.mjs compared clean1280x720 contexts with root vs /index.html. Root became /?demo=1&squad=1&cardrpg2=1&a6=1 and showed the café in2376.335ms. Direct /index.html stayed on the old onboarding screen in2108.143ms. Both had zero pageerrors. [S2-ENTRY]

Chosen method: use the current local café fixture for baseline journey measurement, retaining its resolved URL in every run. Separately flag the default production-entry defect for S3 and repeat the full journey through production preview in S8. Rejected treating a working development redirect as proof the shipping entry is correct. The experiment found an actual routing discrepancy rather than measuring synthetic user data.
