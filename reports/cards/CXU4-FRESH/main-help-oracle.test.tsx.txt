import { readFileSync } from 'node:fs';

 try {

 for(const [value,key] of [[0,'base'],[1,'firstClear']] as const) withConfigV2({boss:{firstClearKeys:value}},()=>{

 });

 expect(Array.from(container.querySelectorAll('.help-step-item')).map(n=>compact(n.textContent!))).toEqual(expected.classic);
 } finally {cleanup();vi.unstubAllEnvs();}
});
