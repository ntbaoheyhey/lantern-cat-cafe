# Exact label candidate pruning (prototype)

The production profile attributes 1652 ms of exclusive sampled wall time in a 32 s, 4× stress run to the rectangle-candidate evaluator in `squad/turn3d/label-layout.ts`. Both HP and number lanes use its results; the cinematic exclusion rectangles also depend on them. The proposal preserves that work's outputs while avoiding collision tests for candidates whose exact score cannot beat the existing winner.

The candidate computes the same `dx`, `dy` and score immediately after the same clamping, then returns when `!(cost < bestCost)`. It retains enumeration order, the strict winner test, overlap padding, fallback spacing and Map insertion order. The current winner can only be replaced by a strictly lower score, so rejecting equal, larger or unordered scores cannot change the result for the existing numeric input records. No placement cache or approximate geometry is introduced.

The original-source oracle passed 1,006 deterministic crowded, impossible and numeric cases without input mutation. A browser prototype then matched every one of 6,418 actual calls across normal and 4× seeded boss play, covering seven labels and fourteen obstacles. Those paired calls execute both solvers and are correctness evidence, not performance evidence.
