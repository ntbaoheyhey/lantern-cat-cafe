## 2. Problems Found and Fixed

1. **Missing v2 database documentation in `docs/database.md`**  
   *Root cause:* `docs/database.md` was written during wave B and never updated when the v2 database migration `20261101000000_v2_cat_rpg.sql` and `20261102000000_v2_integrity.sql` were committed.  
   *Fix:* Added all 6 v2 tables and 8 v2 database functions to `docs/database.md`.

2. **Inaccurate salvage reward claim in `docs/api-v2.md`**  
   *Root cause:* `docs/api-v2.md` claimed salvage returns Fish, but `packages/game-rules/src/v2/content/recipes.ts` and `SalvageResultV2` refund only Yarn and materials with 0 Fish.  
   *Fix:* Corrected `docs/api-v2.md` to explicitly note Fish is always 0 as salvage refunds no currency.

3. **Ambiguous first-clear chest quantities in `docs/play-v2.md`**  
   *Root cause:* `docs/play-v2.md` stated Fish (400 to 6,400) and Yarn (20 to 320) which conflated average expected values with chapter roll ranges.  
   *Fix:* Clarified both roll ranges (`300–500` in Ch1 to `4,800–8,000` in Ch5) and their corresponding averages (`400` to `6,400`).

4. **Missing Relic testnet clarification in Forge and onboarding copy**  
   *Root cause:* In-game copy mentioned "Avalanche Fuji" without explaining to players that Fuji is a test network where minting is free and costs no real money.  
   *Fix:* Updated `ForgePanel.tsx`, `MintPanel.tsx`, `StageLayout.tsx`, and `HowToPlay.tsx` to clarify that Avalanche Fuji is a free testnet costing zero real currency.

5. **Jargon in ClassPicker subtitle**  
   *Root cause:* Subtitle used clinical terminology ("Select a feline combat specialization").  
   *Fix:* Replaced with friendly, thematic cat-café copy ("Pick your cat's class! You can switch anytime outside boss fights.").

6. **Broken link in class art README on branch creation**  
   *Root cause:* `docs/class-looks/README.md` referenced `docs/class-looks-fallback.md` which was unmerged from the preview branch.  
   *Fix:* Brought over `docs/class-looks-fallback.md` and made `docs/class-looks/README.md` fully self-contained, resolving all link-check warnings.
