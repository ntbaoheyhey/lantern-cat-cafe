# V0 — alpha idle converter

Branch `codex/v9-tools`, base `v5-m1.15`. Started 2026-11-19 05:59 UTC; two-hour cap. V8/Batch M is cancelled.

The entry point is `tools/v9/alpha/convert-idle.sh <png-dir|.mov|.zip> <cat> [--cutin N]`. Setup, fallback MOV decoding, loop treatment and metadata conventions are in `tools/v9/alpha/README.md`. Final exports share a common source pixel scale, confirmed by the owner in this chat. Convert final Mochi first to establish 720 px, then Clover and Soot to retain that scale. Existing MP4 framing differs, so the temporary Clover uses an explicit 0.95 ratio, labelled provisional in metadata.

Temporary source material: `/Users/bao/Downloads/Scene1.mp4` and `/Users/bao/Downloads/clover.mp4`, each 300 frames at 30 fps. Keying retains enclosed dark regions and removes black premultiplication from exterior edge pixels. These are stand-ins; final transparent designer frames bypass the keyer. No Soot stand-in is fabricated.

Per-cat delivery is `apps/web/public/units/<cat>/designer/{idle.webm,idle.mov,poster.webp,cutin.png,meta.json}`. A fixed union alpha crop with four-percent margins preserves source motion. Full-resolution cut-ins are retained. Browser coordinates use pixel `feetY`; normalized `anchor` is also included. The default cut-in is a head-symmetry heuristic, with an explicit 1-based override.

Delivered both 300-frame placeholders with VP9 alpha and HEVC alpha.
