# Automation and the earnings target

The simulation counts modeled active play, excluding unused or AFK hours. A bot stops after the existing daily reward cap. Declaring that account active for its entire twelve-hour budget would improve the reported ratio without changing either its rewards or its work.

The server sees authenticated accounts, completed routes, earned proofs, balances and requests. It does not see the model's profile label. An automated account that submits the same valid actions as a regular player receives the same entitlements. Caps, cooldowns and a smaller Spool faucet constrain supply and concentration, but do not establish a guaranteed half-rate per active hour.

We therefore retain the failed automation target. None of the following is presented as a fix: a bot-only reward coefficient, counting idle budget as work, assuming bots cannot own a Deed, excluding automated sellers from markets, or charging a Deed to play or earn.

The rounds explore real prices, rewards, reserve limits and withdrawal caps. Their raw scenario tables show whether those policies change the measured automation ratio. An observable anti-automation intervention would need measured false-positive and evasion rates, a server implementation and a separate sensitivity audit before it could justify a better claim.

For launch review, track rewards per completed route, rewards per modeled active hour, linked withdrawals, funded sales, concentration, cooldown bypass attempts and legitimate-player rejection rates. The current hourly target uses withdrawn YARN and does not establish total net market profitability. This limitation makes the current failed result more serious; it is not an exemption.

No invasive identity gate or anti-bot system has been silently added. A fully adaptive bot that imitates a human remains an explicit adversarial case. The user's permitted E3 PARTIAL route remains conditional on the minimum search counts, independent confirmation, the required burn/Thread/progression targets and an honest Pareto review.
