The existing default-off economy flag controls all three recipes. No contract or migration is added. The issuer reserves Star Thread and any input gear, then verifies the exact existing YarnToken `sealPayments` burn before returning an improved item or a permanent style unlock. Repeat reservations, stale concurrent requests and replayed finalizations cannot charge twice. Cosmetic outputs never receive NFT vouchers.
