# Non-battle UI baseline audit

Actual rendered local screens, settled lazy content; visible DOM text with numeric runs excluded and overlay occlusion checked. Scores are explicit visual judgments, not an automated quality claim. Local account fixtures and Anvil only. No reference pixels enter the repository.

53 states inspected. Reference comparisons are private files outside git. The home artwork is strongest; collection, bag dialogs, receipts and the nested Fuji rails need structural work. Several help dialogs have pale text on pale panels. A short word count alone does not imply legibility.

## Missing or combined surfaces

- Hero information/level/star share the collection Growth panel; recorded as cats-list and hero-level-star rather than invented separate screens.
- Batch-use quantity dialog is absent; bag-manage records the existing destination and the missing control.
- Market item preview/listing/confirmation are embedded or absent; market-browse/list/buy record the actual destinations.
- Season track/countdown/edition supply share one panel; the track is a placeholder.
- Settings has no language selector.
- Events currently routes to daily gifts.
- No separate reward/level-up overlay exists in the owned result flow; victory records the existing wrapper.
