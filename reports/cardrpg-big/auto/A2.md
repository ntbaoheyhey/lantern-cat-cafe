# A2 default automatic kits
REFERENCE: packages/game-rules/src/cardrpg/depth/state.ts, battle.ts, run.ts, contract.ts, save.ts

New encounters derive each cat's three ordinary skills and add its ultimate at level 6 or three stars. Team selection, rows, equipment and progression determine the kit. Campfire upgrades and encounter rewards use the same unlocked skill list.

Version 0.6 saves use the THC6 envelope. Import accepts THC5 version 0.5 and legacy 0.4 JSON. Migration updates version markers and retains pending actors, RNG, initial setups and recorded choices. A pending three-skill encounter finishes with its recorded kit. Subsequent encounters derive the new default kit.

## Paired simulations
REFERENCE: reports/cardrpg-big/sim/auto-a1*.json, auto-a2*.json, tools/cardrpg-big/auto-sim.mjs

Each row uses 50 training seeds and 50 held-out seeds for each chapter, on the same seven-node safe route. Level-6 fixtures retain starter equipment and one star. The baseline uses the A1 controller with the previous three-skill kits.

The level-1 results match A1. Chapter-1 starter difficulty remains open for phase I. Level-6 results show the substantial contribution from unlocked ultimates in this sample. These are measured samples of this route and these teams.
