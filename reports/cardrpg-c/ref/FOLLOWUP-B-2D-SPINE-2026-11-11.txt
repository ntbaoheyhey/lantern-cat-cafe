2. ARCHITECTURE (you decide details; these are the requirements)
=====================================================================
2.1 Runtime
- Use the official Spine web runtime that fits the battle renderer. Default: @esotericsoftware/spine-threejs inside the existing three.js battle with an OrthographicCamera (keeps the actor/event API and the A6 seams). If your research shows spine-webgl/spine-pixi or Phaser's spine plugin is clearly better for quality/perf, you may switch the battle renderer, but keep the same actor/event API and record it in DECISIONS.md.
- Runtime major.minor MUST match the designer's Spine editor version. Until the designer's version is known, use 4.2 and make the version one constant; NEEDS-USER.md asks for the version.
- New flag lookSpine (default ON in demo/look mode). Per unit: designer skeleton if accepted, else placeholder skeleton, else old puppet renderer as last fallback.
- Premultiplied alpha correct (no dark fringes), linear filtering, atlas pages <= 2048, one skeleton data cache per unit, AnimationState per actor, no per-cast allocation, mix durations set (0.1-0.2 s) between all clips.
- Events drive gameplay presentation: `hit` -> damage number + hurt on target + hit VFX; `cast` -> skill VFX start; `ult-start`/`ult-end` -> ult cut-in/zoom/dim. If an animation has no event, fall back to a timed default and log it in the intake report.
- Sockets manifest per unit built from bone names: hp-anchor, head, vfx-origin, main-hand, off-hand, root (feet). Same socket names A6 already reads (hpAnchor, head, vfxOrigin, mainHand, offHand, feet) — map them, do not rename A6's side.

2.2 Stage and camera
- 2D side view. Party formation left (3 slots, slight depth stagger by y and scale <= 1.06), enemies right, boss center-right. Shadows = soft ellipse sprites.
- Backdrop: 3 parallax layers (back wall, mid furniture, foreground props) of the cafe. Placeholder now: render the existing cafe.glb from a fixed side camera with toon post + outline pass into PNG layers, then simplify (flat color bands + dark outline) so it matches the cartoon style. The designer may repaint it later (wave 3).
- Ult: brief camera push-in (ortho zoom <= 1.15), background dim, impact frames; reduced-motion mode disables shake/zoom.

2.3 Placeholders (so the game runs from day 1 with one path)

2.5 2D VFX

3. DESIGNER CONTRACT (save as reports/cardrpg-look/art-rebuild/DESIGNER-SPEC.md; the validator enforces it)
=====================================================================
3.1 PSD: RGB 8-bit, transparent, one layer per moving part, occluded joint areas painted underneath, styles/masks rasterized, layer names lowercase-kebab with l-/r- prefixes (head, r-ear, l-arm-upper, l-arm-lower, l-hand, tail-1...), variants grouped (eye-l: open/half/closed). All characters face RIGHT in 3/4 view; the game flips enemies. Light from top-left. Outline dark warm brown (not pure black), ~10-12 px at a 1024 px cat; bosses use the SAME pixel outline width. Palette per ART-DIRECTION.md. Exported with the official PhotoshopToSpine script.
3.2 Size (1.00 = cat; PSD drawn at 2x, Spine import scale 0.5): cats 1024 px PSD / 512 units (all 12, every rarity, +-3%); small enemies 410-512 units; standard/elite 563-666; bosses 870-998, width <= 2.2 x 512. Root bone at center between the feet, ground y = 0. Height = feet to top of head/ears in setup pose, excluding raised props.
3.3 Required bones: root, hip, head, hp-anchor, vfx-origin, main-hand, off-hand.
3.4 Required animations: idle (loop 2-3 s), appear (0.5-0.8 s), attack (0.6-0.9 s, event hit), skill (0.8-1.2 s, events cast + hit), ult (1.5-2.5 s, events ult-start, hit (1+), ult-end), hurt (0.3-0.4 s), ko (0.8-1.2 s, holds last pose), victory (loop 1.5-2 s). Bosses add idle-phase2 and enrage. Budgets: cat <= ~40 bones and ~400 mesh vertices, boss <= ~80 bones, <= 1 clipping attachment. Export JSON or .skel, atlas pages <= 2048x2048, premultiplied alpha ON, padding 2-4, files named <unit-id>.json/.atlas/.png.
3.5 Delivery folder: <unit-id>/source/<unit-id>.psd + .spine ; export/<unit-id>.json .atlas .png ; preview.mp4 or .gif ; notes.txt (Spine version, tools, statement that it is original and not based on other games' art).
3.6 Validator severity: names/bones/animations/version/height = FIX (unit stays placeholder, feedback sent); budgets/event timing/outline width = WARN (accepted, feedback sent).
