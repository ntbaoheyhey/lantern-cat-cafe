# Archived evidence

To retain exact raw records within the 120 MB evidence limit, the two completed source/offline VFX cue `review.json` files are stored in `checks/archive/vfx-cue-reviews.tar.gz`. Screenshots and other receipts stay in place. The adjacent manifest lists original paths, byte lengths and SHA256 values. Extraction was verified byte-for-byte before archiving; no acceptance run was repeated.

Read either original from the repository root with `tar -xOf reports/cardrpg-c/checks/archive/vfx-cue-reviews.tar.gz reports/cardrpg-c/shots/c11-vfx-cues/review.json` (or `c11-vfx-cues-offline/review.json`).
